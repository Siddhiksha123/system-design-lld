# System Design - Low Level Design (LLD)

This repository contains implementations of various system design problems using Java.

## Projects

### LinkedIn LLD
- Connection management system
- User repository with CRUD operations
- Notification system with Strategy pattern
- Observer pattern implementation

### Future Projects
- Twitter LLD
- Uber LLD
- Amazon Warehouse LLD

## Structure

```
system-design-lld/
├── linkedin/
│   ├── constants/
│   ├── entity/
│   ├── repository/
│   ├── service/
│   └── Main.java
├── .gitignore
└── README.md
```

## How to Run

1. Navigate to the project folder
2. Compile: `javac -d out linkedin/**/*.java`
3. Run: `java -cp out linkedin.Main`

## Technologies Used

- Java 8+
- Design Patterns (Strategy, Observer, etc.)
- OOP Principles
